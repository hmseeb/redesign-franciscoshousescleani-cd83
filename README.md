# Francisco's House Cleaning Services — Website

A complete, from-scratch redesign of the marketing site for **Francisco's House Cleaning Services LLC**,
a professional house, apartment, office and commercial cleaning company based in Philadelphia, PA and
serving Pennsylvania, New Jersey and Delaware.

## Stack

Vanilla HTML, CSS and JavaScript — no framework, no build step, no dependencies.
Open `index.html` in a browser, or serve the folder statically.

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Structure

```
index.html            Single-page site (semantic HTML + JSON-LD LocalBusiness schema)
assets/css/styles.css Design system, layout and responsive rules
assets/js/main.js     Nav, scroll reveal, stat counters, FAQ accordion, estimate form
favicon.svg           Favicon (gold monogram on ink)
robots.txt            Crawler directives
sitemap.xml           Sitemap
```

## Sections

Utility bar · sticky header · hero with stats · services (11 cleaning services) ·
why choose us (six reasons + current offers) · how it works · areas we serve (15 cities) ·
FAQ · contact + free-estimate form · footer · mobile sticky call bar.

## Design

- **Palette:** ink navy (`#0B1222`) with the brand's gold gradient (`#D9A93A` / `#F0D083`)
- **Type:** Plus Jakarta Sans (UI) + Fraunces (display accents), with system fallbacks
- **Responsive:** mobile-first, fluid type, breakpoints at 600 / 860 / 960 / 1180px
- **Accessibility:** skip link, semantic landmarks, focus-visible styles, descriptive alt text,
  `prefers-reduced-motion` support, ARIA labelling on the nav and form
